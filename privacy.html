Privacy policy

job-funnel · last updated 12 November 2026

Who uses it

job-funnel is a personal tool. Its only user is its developer, who connects their own Gmail account. It is not offered to the public.

What it accesses

With the user's consent, job-funnel uses the Gmail API with the read-only scope gmail.readonly. It looks at the sender and subject of new messages and downloads the body only of job-search mail (applicant-tracking systems, job boards, recruiters). It never sends, modifies or deletes mail.

What it keeps and where

The job-search messages it downloads, and what it derives from them (applications, replies, job descriptions), are stored in the user's own private database and on the user's own computer. The Google sign-in token is stored only on the user's computer.

Sharing

Nothing is sold, shared with third parties, used for advertising, or used to train AI models. Data is used only to show the user their own job-search progress.

Google API Services User Data Policy

job-funnel's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be removed at any time at myaccount.google.com/permissions. The user can delete the stored data by deleting their database.

Contact

Open an issue on this site's repository.
